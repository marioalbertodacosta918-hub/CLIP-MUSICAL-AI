# CLIP MUSICAL AI V2 (prévia)
Esta atualização foi preparada em branch separado, sem alterar a versão publicada.
## Modos
- Somente música: gera cenas abstratas gráficas no próprio navegador (não são imagens criadas por IA).
- Música + imagem: anima uma imagem com movimento de câmera.
- Música + várias imagens: organiza fotos em sequência.
- Música + vídeos: lê vídeos selecionados, utiliza a imagem dos vídeos (sem som) e a música principal.
## Novidades
Categorias musicais, estilos visuais ampliados, exportação quadrada (1:1), letra opcional, linguagem genérica para todos os gêneros.
## Limites
- A sincronização automática atual distribui os versos igualmente no tempo: não é transcrição automática nem reconhecimento da voz.
- Exportação WebM depende de MediaRecorder/Canvas no navegador; MP4 ainda não está implementado.
- IA generativa externa ainda não está integrada.
- Testes funcionais em celular e publicação no Hatchable ainda estão pendentes.
## Segurança
Branch `feat/clip-musical-ai-v2`. A branch `main` permanece intacta até revisão/mesclagem.
